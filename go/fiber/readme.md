## Fiber

An Express-inspired web framework written in Go.
Fiber is a Go web framework built on top of Fasthttp, the fastest HTTP engine for Go. It's designed to ease development with performance in mind.

* Programming Language: Golang
* Website: https://gofiber.io/
* Docs: https://docs.gofiber.io/
* Github: https://github.com/gofiber/fiber

### Installation
* Init:
```bash
mkdir fiber
cd fiber
go mod init fiber
go get github.com/gofiber/fiber/v3
touch server.go
```
* Dev:
```bash
go run server.go
```
* Build:
```bash
go build -o fiber
```

Port: 3000
