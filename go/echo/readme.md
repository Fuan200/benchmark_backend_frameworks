## echo

Build fast Go APIs.
Without the bloat.
A high-performance, minimalist Go web framework — a zero-allocation router, batteries-included middleware, and an expressive API. Ship production services in minutes.

* Programming Language: Golang
* Website: https://echo.labstack.com/
* Docs: https://echo.labstack.com/guide/quickstart/
* Github: https://github.com/labstack/echo

### Installation
* Init:
```bash
mkdir echo
cd echo
go mod init echo
go get github.com/labstack/echo/v5
touch server.go
```
* Dev:
```bash
go run server.go
```
* Build:
```bash
go build -o echo
```

Port: 1323
