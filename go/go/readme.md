## Go 

Go with Standard library (net/http)

Package http provides HTTP client and server implementations.

Get, Head, Post, and PostForm make HTTP (or HTTPS) requests.

* Programming Language: Golang
* Docs: https://pkg.go.dev/net/http@go1.27.0

### Installation
* Init:
```bash
mkdir go
cd go
go mod init go-standard-http-library
touch main.go
```
* Dev:
```bash
go run main.go
```
* Build:
```bash
go build -o go
```

Port: 8080
